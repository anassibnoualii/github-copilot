## Step 1 — Install the GitHub Copilot Plugin for IntelliJ

Open IntelliJ IDEA and go to **Settings → Plugins → Marketplace**. Search for **"GitHub Copilot"** and install the official plugin by GitHub (`com.github.copilot`).

Or install directly from the JetBrains Marketplace:

1. Go to **Settings** (`Ctrl+Alt+S` / `⌘,`)
2. Select **Plugins → Marketplace**
3. Search **GitHub Copilot**
4. Click **Install** → **Restart IDE**

<Callout variant="tip" label="Compatible IDEs">
The GitHub Copilot plugin works across all JetBrains IDEs: IntelliJ IDEA, PyCharm, WebStorm, GoLand, Rider, CLion, and others. Install the same plugin from the same Marketplace.
</Callout>

## Step 2 — Sign In to GitHub

After the IDE restarts:

1. Go to **Settings → Tools → GitHub Copilot**
2. Click **Log in to GitHub**
3. A browser window opens — authorize the plugin to access your GitHub account
4. Return to IntelliJ — the Copilot status icon appears in the bottom status bar

Your account needs an active Copilot subscription (Free, Pro, Pro+, Business, or Enterprise).

<Callout variant="warning" label="SAML SSO organizations — extra step required">
If your organization enforces SAML SSO, authentication will silently fail with 403 errors after sign-in. Fix it: go to **GitHub.com → Settings → Developer Settings → Personal access tokens**, find the token named "GitHub Copilot Plugin", click **Configure SSO**, and authorize it for your organization. This step is required once per account per org.
</Callout>

<Callout variant="tip" label="Status bar icon">
The GitHub Copilot icon in the bottom-right status bar shows connection state. Click it to enable/disable completions or open Copilot settings without navigating to the Settings menu.
</Callout>

## Step 3 — Install the Copilot CLI

The CLI lets you run agentic tasks from your terminal. Node.js 22 or later is required.

```bash
# Via npm (recommended — works everywhere)
npm install -g @github/copilot

# Via Homebrew (macOS / Linux)
brew install copilot-cli

# Via winget (Windows)
winget install GitHub.Copilot
```

Verify the install:

```bash
copilot --version
```

Start your first session from a project root:

```bash
cd your-project
copilot
```

<Callout variant="warning" label="Node.js version">
The CLI requires Node.js 22 or later. Check with `node --version`. Use `nvm install 22 && nvm use 22` to upgrade without affecting other projects.
</Callout>

## Step 4 — Authenticate the CLI

On first run, `copilot` opens a browser window for GitHub OAuth. Authorize the app and return to your terminal — the token is stored in your system keychain automatically.

## Step 5 — Network and Proxy Setup (Enterprise)

If your organization uses a corporate proxy or TLS inspection, complete this before Step 2.

**Configure IntelliJ proxy:**
1. Go to **Settings → Appearance & Behavior → System Settings → HTTP Proxy**
2. Select **Manual proxy configuration**
3. Enter your proxy host and port
4. Enable **Proxy authentication** if required

**Required domains to whitelist** (add to your firewall/proxy allowlist):

```
github.com
api.github.com
copilot.github.com
copilot-proxy.githubusercontent.com
default.exp-tas.com
```

<Callout variant="warning" label="TLS inspection / self-signed certificates">
If your proxy performs TLS inspection, the CA certificate must be trusted by IntelliJ's JVM. Go to **Settings → Tools → Server Certificates → Accept non-trusted certificates automatically** as a last resort, or add the CA cert to IntelliJ's trust store at **Help → Edit Custom VM Options** using `-Djavax.net.ssl.trustStore`. The Copilot plugin uses a separate trust chain from your OS trust store.
</Callout>

## Step 6 — Verify Everything Works

In IntelliJ, open any Java file and start typing a method body — a grey ghost text suggestion should appear within 1–2 seconds. Press `Tab` to accept.

```bash
# In terminal — test the CLI
copilot "list all Java files larger than 50KB in this directory"
```

Both should respond within a few seconds. If inline completions do not appear in IntelliJ, check **Settings → Tools → GitHub Copilot → Enable GitHub Copilot**.
