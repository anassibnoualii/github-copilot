## Copilot Settings in IntelliJ IDEA

All Copilot configuration lives in **Settings → Tools → GitHub Copilot**. There is no settings file to edit — everything is UI-driven and stored in IntelliJ's application settings.

## Key Settings to Configure

| Setting | Recommended value | What it does |
|---------|-----------------|-------------|
| **Enable GitHub Copilot** | On | Master toggle — turns completions on/off globally |
| **Enable auto-completions** | On | Ghost text appears as you type |
| **Show completions for...** | All file types | Then disable individually below |
| **Custom instructions file** | `.github/copilot-instructions.md` | Loads repo rules into every chat session |

## Per-Language Control

Disable completions for file types where they add noise. IntelliJ uses **language IDs**, not file extensions, in the Disabled languages list:

1. Go to **Settings → Tools → GitHub Copilot**
2. Under **Completions**, find **Disabled languages**
3. Add: **Properties** (covers `.properties` files), **XML**, **JSON** if desired

<Callout variant="warning" label=".env files — use Content Exclusions, not language toggles">
`.env` files have no language ID in IntelliJ, so the Disabled languages list does not cover them. The correct way to exclude `.env` files from Copilot is via **org-level Content Exclusions** (enforced server-side) or a `.copilotignore` file (client-side hint). Both approaches are described below.
</Callout>

## IntelliJ Keyboard Shortcuts for Copilot

| Shortcut | Action |
|----------|--------|
| `Tab` | Accept the current inline suggestion |
| `Esc` | Dismiss the suggestion |
| `Alt+]` | Show the next suggestion |
| `Alt+[` | Show the previous suggestion |
| `Alt+\` | Trigger Copilot manually (force a suggestion) |
| `Alt+Enter` | Open the inline suggestions panel |

Open the Copilot Chat panel via **View → Tool Windows → GitHub Copilot** or click the Copilot icon in the right gutter.

## Copilot Chat in IntelliJ

The chat panel works like a persistent assistant. Open it and ask questions about your code, your project, or general programming topics.

To chat about a specific selection:

1. Select code in the editor
2. Right-click → **GitHub Copilot → Open Chat** (or press `Alt+\`)
3. The selection is automatically included as context

## File Exclusions: Two Layers

There are two ways to exclude files from Copilot — they serve different purposes:

### `.copilotignore` — client-side, per-repo

Create a `.copilotignore` file at the repo root (same syntax as `.gitignore`). This prevents Copilot from using these files as context when you have them open in the editor. Commit it so the whole team benefits.

```
.env
.env.*
*.pem
*.key
*.pfx
secrets/
target/
build/
.idea/
*.iml
```

<Callout variant="info" label="Limitation of .copilotignore">
`.copilotignore` is a client-side hint — it prevents Copilot from proactively reading excluded files. However, content you manually paste into chat is still sent. For guaranteed server-side enforcement, use org-level Content Exclusions.
</Callout>

### Org-Level Content Exclusions — server-side, enforced

Configured in **Organization Settings → Copilot → Content Exclusions**. Excluded files are never sent to the Copilot model, regardless of what any developer does in the IDE.

<Callout variant="warning" label="Propagation delay">
After adding or changing org-level content exclusions, it can take up to 30 minutes for the change to take effect in already-open IDE sessions. Developers must reload the IDE or wait for the next session.
</Callout>

## Enabling Custom Instructions

For IntelliJ to load `.github/copilot-instructions.md` automatically, the plugin version must be 1.5.20 or later. Verify in **Settings → Plugins → GitHub Copilot**. If the version is current, custom instructions are loaded automatically for every chat session.
