## What is GitHub Copilot?

GitHub Copilot is an AI-powered coding assistant trained on billions of lines of public code. It integrates directly into your IDE to provide real-time suggestions as you type — from single lines to entire functions, tests, and documentation.

<Callout variant="info" label="How it works">
Copilot sends your current file, open tabs, and cursor context to an AI model (GPT-4o, Claude, or Gemini depending on your plan). The model returns completions that match the patterns it detected in your code.
</Callout>

## Installing GitHub Copilot

```bash
# VS Code — install from the Extensions panel
code --install-extension GitHub.copilot
code --install-extension GitHub.copilot-chat
```

After installing, you'll be prompted to sign in with your GitHub account. Copilot activates automatically once authenticated.

| Open suggestion panel | Ctrl + Enter | Cmd + Enter |
| Trigger suggestion | Alt + \\ | Option + \\ |
| Accept next word | Ctrl + → | Cmd + → |

## What Context Does Copilot Use?

Copilot reads several sources to build its context window:

1. **Current file** — everything visible in the active editor
2. **Open tabs** — files you have open nearby (not all tabs, just a selection)
3. **File name and path** — `auth.py` signals authentication code
4. **Imports and declarations** — your imports tell Copilot what libraries you use
5. **Comments** — inline comments describing what you want

<Callout variant="tip" label="Better Suggestions">
Write a comment describing what you want before the function. Copilot will often generate the entire implementation from a well-written comment.
</Callout>
